# Voices

Диктовка в любое окно Windows через Gemini. Нажмите `Ctrl+Shift+Space`, скажите текст и нажмите сочетание ещё раз: речь будет распознана, почищена и вставлена туда, где стоит курсор. Русский и английский можно смешивать.

## Скачать

**[⬇ Voices для Windows (x64)](https://github.com/Nikita-Ardashev/voices-releases/releases/latest/download/win-x64-Voices-Setup.zip)** — последняя версия.

Все версии и список изменений — на странице [Releases](https://github.com/Nikita-Ardashev/voices-releases/releases).

## Установка

1. Скачайте `win-x64-Voices-Setup.zip` и распакуйте его в любую папку. Установщик из архива напрямую не запускайте: рядом с ним лежит скрытая папка `.installer`, без которой он не работает.
2. Запустите `Voices-Setup.exe`. Если появится «Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**: установщик пока не подписан.
3. После установки откроется мастер настройки: API-ключ Gemini, микрофон, горячая клавиша, режим, автозапуск.

API-ключ Gemini бесплатный, его можно получить в [Google AI Studio](https://aistudio.google.com/apikey). Ключ хранится только на вашем компьютере.

## Что нужно

- Windows 10 или 11, 64-бит
- Microsoft Edge WebView2 Runtime (в Windows 11 уже есть)
- Микрофон и доступ к интернету

## Обновления

Voices обновляется сам: новая версия скачивается в фоне, а приложение предлагает перезапуститься через меню в трее.

## Поддержать автора

Voices бесплатный. Если он экономит вам время, можно [поддержать автора на CloudTips](https://pay.cloudtips.ru/p/a210b36b) — ссылка есть и в самом приложении, внизу боковой панели и в меню трея.

## Удаление

**Параметры → Приложения → Установленные приложения → Voices → Удалить.** Перед удалением выключите автозапуск в настройках Voices.
